# 🛒 E-Commerce Sales Analysis

## 📌 Overview

This project analyzes an e-commerce dataset of 10,000 orders to understand
sales performance, customer behavior, product performance, and geographic trends.

The project was developed using Python, Pandas, Jupyter Notebook, and Power BI.

## 🎯 Objectives

- Analyze overall sales and order performance
- Identify top-performing categories and products
- Understand customer and geographic performance
- Identify important data-quality issues
- Build an interactive Power BI dashboard

## 📊 Key Insights

- Total Revenue: ₹642.13M
- Total Orders: 10,000
- Unique Customers: 6,016
- Unique Products: 971
- Total Units Sold: 30,144
- Average Order Value: ₹64,212.91
- Electronics generated the highest category revenue.
- North Carolina had the highest state-level revenue.
- Megan Johnson was the highest-revenue customer.

## 🧹 Data Quality

- No missing values were identified.
- 163 sales records were flagged as outliers and retained.
- 4,915 records contained inconsistent shipping/order dates.
- Shipping and delivery-time analysis was therefore excluded.

## 📈 Power BI Dashboard

The project includes a 3-page interactive Power BI dashboard:

1. **Executive Dashboard**
2. **Sales & Product Analysis**
3. **Customer & Geographic Analysis**

The dashboard includes filters for Category, State, and Payment Method.
